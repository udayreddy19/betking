7) ADMIN AUTO-PUBLISH (optional)
--------------------------------
Admin → Comms → Instagram lets you compose caption + image and publish
via Meta Graph API (no password login).

Server env (restart after setting):
  INSTAGRAM_BUSINESS_ACCOUNT_ID=<IG professional account id>
  INSTAGRAM_ACCESS_TOKEN=<long-lived Page token with instagram_content_publish>
  SOCIAL_MEDIA_PUBLIC_BASE_URL=https://oddsyra.com

Setup path:
  1. Professional IG account linked to a Facebook Page
  2. Meta app with Instagram Graph API
  3. Long-lived Page token (instagram_basic, instagram_content_publish,
     pages_show_list, pages_read_engagement)
  4. Put ids/token in .env on the VPS and restart the API

Until tokens are set, Admin still saves drafts; Publish will show setup hints.
Docs: https://developers.facebook.com/docs/instagram-platform/content-publishing
